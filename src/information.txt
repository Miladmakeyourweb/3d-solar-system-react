# 🚀 Build a 3D Solar System with React, Three.js & React Three Fiber

In this project, we build an interactive 3D Solar System using React, Three.js, and React Three Fiber.

The project includes the Sun, all 8 planets, realistic textures, animated orbits, a star-filled space environment, and interactive planet selection.

## 💻 1. Requirements

Before starting, install the following:

* Node.js (LTS version)
* Visual Studio Code
* npm (included with Node.js)
* Basic knowledge of JavaScript and React

Download:

* Node.js: https://nodejs.org/
* Visual Studio Code: https://code.visualstudio.com/

## 📁 2. Create a React Project with Vite

Open your terminal (CMD or VS Code Terminal) and run:

```bash
npm create vite@latest cosmos -- --template react
```

Go into the project folder:

```bash
cd cosmos
```

Install the project dependencies:

```bash
npm install
```

## 📦 3. Install Required Libraries

Install Three.js:

```bash
npm install three
```

Install React Three Fiber:

```bash
npm install @react-three/fiber
```

Install Drei:

```bash
npm install @react-three/drei
```

These libraries are used to create and display the interactive 3D Solar System.

## 🗂️ 4. Project Folder Structure

Organize your project like this:

```text
cosmos/
│
├── public/
│   └── textures/
│       ├── sun.jpg
│       ├── Mercury.jpg
│       ├── Venus.jpg
│       ├── earth.jpg
│       ├── clouds.jpg
│       ├── Mars.jpg
│       ├── Jupiter.jpg
│       ├── Saturn.jpg
│       ├── Uranus.jpg
│       └── Neptune.jpg
│
├── src/
│   ├── App.jsx
│   ├── App.css
│   ├── main.jsx
│   └── index.css
│
├── index.html
├── package.json
└── vite.config.js
```

## 🌍 5. Planet Textures

Add your planet texture images inside:

```text
public/textures/
```

Required textures:

* sun.jpg – Sun texture
* Mercury.jpg – Mercury texture
* Venus.jpg – Venus texture
* earth.jpg – Earth texture
* clouds.jpg – Earth cloud layer
* Mars.jpg – Mars texture
* Jupiter.jpg – Jupiter texture
* Saturn.jpg – Saturn texture
* Uranus.jpg – Uranus texture
* Neptune.jpg – Neptune texture

IMPORTANT: Texture filenames must match the paths used in your code, including uppercase and lowercase letters.

## ⚙️ 6. Start Coding

Open the project in Visual Studio Code:

```bash
code .
```

Main files:

* App.jsx: Main React application and 3D Solar System components.
* App.css: Styling, layout, planet selector, and interface design.
* main.jsx: React application entry point.
* index.css: Global CSS styles.

Use React Three Fiber to create the 3D scene, Three.js to handle 3D objects and materials, and Drei for useful 3D helpers.

## ▶️ 7. Run the Project

Start the Vite development server:

```bash
npm run dev
```

Open the local URL shown in your terminal, usually:

```text
http://localhost:5173/
```

Your 3D Solar System should now be running in your browser!

## 🐛 Troubleshooting

If the project does not start:

1. Make sure Node.js is installed.
2. Run `npm install`.
3. Check that all texture images exist inside `public/textures/`.
4. Check texture filenames and file extensions.
5. Check the browser console for errors.
6. Restart the development server using `npm run dev`.
